## milestone:the-bend

**Reading (basis.path).** The target is a *definitively* passed peak of global **all-GHG** emissions. A fossil-CO₂, electricity or regional peak does not count. Operational recognition, forecast only: annual all-GHG inventories show the peak ≥ 3 years behind, emissions ≥ 1% below it, plus one reporting cycle. This is a detection heuristic; actual achievement still needs a verified primary event. **DEFINITION sensitivity**: the threshold 0.5% / 2% moves p50 to 2035.4 / 2039.1 (a 3.7-year span), and a "physical peak year passed" reading gives p50 2030.7. Those are > 2 years, so this is a definition crux for the owner.

## Appendix C: model script (calculate.py, final version)

Run: `uv run --with numpy python calculate.py` (inputs: the two GCB series CSVs written by `ledger.py series climate <metric> --as-of 2026-10-14`). 2 GiB address-space cap; 50,000 draws in chunks of 2,000 × 751 grid points (~12 MB per array).

```python
# Climate milestone ETA model, assess run 20261014T161054Z (rubric v5, audit 2026-10-14-r1).
# Shared component trajectory (fossil CO2 / net land-use CO2 / non-CO2) for Bend, Balance, Ceiling.
# Memory bounded: 2 GiB address-space cap, draws processed in chunks of 2,000 x 751 grid points.
import json, math, pathlib, resource
import numpy as np
resource.setrlimit(resource.RLIMIT_AS, (2 * 1024**3, 2 * 1024**3))
P = pathlib.Path(__file__).parent
def load(name):
    return {int(l.split(',')[0]): float(l.split(',')[1]) for l in (P / f'{name}.csv').read_text().splitlines()}
fossil = load('co2-emissions-fossil-gcb'); total = load('co2-emissions-total-gcb')
luc = {y: total[y] - fossil[y] for y in fossil}

# --- measured inputs -------------------------------------------------------------
dec = {y: math.log(fossil[y + 10] / fossil[y]) / 10 for y in (1995, 2005, 2015)}   # centred y+5.5
a_f = (dec[2005] - dec[2015]) / 10                         # latest fossil deceleration /yr^2
dec_t = {y: math.log(total[y + 10] / total[y]) / 10 for y in (1995, 2005, 2015)}
a_tot = (dec_t[2005] - dec_t[2015]) / 10
ys = np.arange(2006, 2026); lv = np.log([luc[int(y)] for y in ys])
gL, cL = np.polyfit(ys, lv, 1)                              # OLS log-linear net land-use CO2
resid_sd = float(np.std(lv - (gL * ys + cL), ddof=2))
gL_se = resid_sd / math.sqrt(float(((ys - ys.mean())**2).sum()))
L0 = float(math.exp(gL * 2025 + cL))                        # trend level 2025 (2025 obs 4.1 is ENSO-low)
F0 = fossil[2025]                                           # 38.1 Gt, centred 2025.5
N0 = 54.1 - 38.1                                            # EDGAR excl LULUCF minus fossil CO2 (assumed split)
gT = math.log(1.003)                                        # Climate TRACE Jan-Jul 2026 all-GHG, at 2026.5
gF_2025 = dec[2015] - 5 * a_f                               # fossil log-rate at 2025.5 from centred decade
B2_pts_z = [-0.954165, -0.439913, 0.0, 0.439913, 0.954165]  # CDF .17/.33/.50/.67/.83
# AR6 WG1 Table SPM.2, 2.0C budgets from 2020 at 83/67/50/33/17 % likelihood: 900/1150/1350/1700/2300
em_2020_25 = sum(total[y] for y in range(2020, 2026))       # 247.66 Gt
rev = (500 - em_2020_25) - 170                              # GCB 2025 1.5C (50%) 170 Gt vs AR6-implied
B2_pts = [b - em_2020_25 - rev for b in (900, 1150, 1350, 1700, 2300)]
r_ren = math.log(5.15 / (5.15 - 0.693)); S0 = 0.0012

N = 50000; CH = 2000; T0 = 2025.5; dt = 0.1
grid = T0 + dt * np.arange(0, 751)                          # 2025.5 .. 2100.5
rng = np.random.default_rng(20261014)
D = {k: rng.standard_normal(N) for k in ('za', 'zT', 'zF', 'zL', 'zN0', 'zS', 'zr', 'zB', 'zZEC', 'zNC')}
D.update({k: rng.random(N) for k in ('uR', 'uS1', 'uS2', 'uN')})

def b2_tcre(z):
    zz, bb = np.array(B2_pts_z), np.array(B2_pts)
    out = np.interp(z, zz, bb)
    lo = z < zz[0]; hi = z > zz[-1]
    out[lo] = bb[0] + (z[lo] - zz[0]) * (bb[1] - bb[0]) / (zz[1] - zz[0])
    out[hi] = bb[-1] + (z[hi] - zz[-1]) * (bb[-1] - bb[-2]) / (zz[-1] - zz[-2])
    return out

Fc = F0 * math.exp(gF_2025 - 0.5 * a_f); Lcc = L0 * math.exp(gL); gFc = gF_2025 - a_f
Nc = N0 * math.exp(gT)
gN_c = ((Fc + Lcc + Nc) * gT - Fc * gFc - Lcc * gL) / Nc        # implied non-CO2 log-rate at 2026.5

BASE = dict(a_logsd=0.50, a_mult=1.0, a_override=None, m_nonco2=1.0, gmin=None, gT_sd=0.003,
            pS1=0.10, pS2=0.05, r_mult=1.0, r_sd=0.05, seed_logsd=1.0, bend_drop=0.01, bend_years=3.0,
            bend_report=1.0, bend_floor=2029.0, zec_sd=440.0, nc_sd=172.0, b2_shift=0.0, gL_sd=0.006,
            gF_sd=0.00105, N0_sd=2.0, L0o=None, gLo=None, gN_shift=0.0, anchor=True, kprior=False, bal_aggregate=False)

def run(**over):
    p = dict(BASE, **over)
    res = {'bend': [], 'balance': [], 'ceiling': [], 'ceiling_alt2100': [], 'co2_netzero': [], 'cum': [],
           'bend_alt_physical_peak': [], 'balance_alt_10pct_no_removal': [], 'peak': []}
    for s in range(0, N, CH):
        sl = slice(s, s + CH); n = min(CH, N - s)
        a = (p['a_override'] if p['a_override'] else a_f * p['a_mult']) * np.exp(p['a_logsd'] * D['za'][sl])
        tau = grid[None, :] - T0
        gF0 = dec[2015] - 5 * a + p['gF_sd'] * D['zF'][sl]              # same decadal anchor, per-draw curvature
        gLd = (p['gLo'] if p['gLo'] is not None else gL) + p['gL_sd'] * D['zL'][sl]
        L0d = p['L0o'] if p['L0o'] is not None else L0
        N0d = N0 + p['N0_sd'] * D['zN0'][sl]
        def logpath(g0, aa):
```
