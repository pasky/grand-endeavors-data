### 3. Model and time-to-target
Per draw, on a 0.1-yr grid from 2026 to 2100.5:
- **Net CO₂** = G_eff − C(t), with C on the S-curve. It may go negative after net zero.
- **WE_m(t)**, the non-CO₂ warming equivalent = f_s·(4.53·N_eff(t) − 4.25·N_eff(t−20)) + (1 − f_s)·N_eff(t), with f_s = .65. The pre-2025.5 history is back-cast at +0.8%/yr (assumed); it cancels against the reference pathway.
- **WE_p**, the reference pathway: N linear from its 2025.5 level to N_p ~ N(8, 1.82) at 2070, then flat. cumWE_p = ∫_{2026}^{2070} WE_p, with p10/50/90 −142 / 2 / 147 GtCO₂-we.
- **X(t)** = ∫_{2026}^{t} (net CO₂ + WE_m) − cumWE_p. Warming(t) − 2°C ∝ X(t) − B2, with TCRE common to both sides.
- **Peak** t* = argmax X over [2026, 2100.5]. Success = no S2, t* < 2100.5, held (net CO₂(2100) + (0.28·f_s + 1 − f_s)·N_eff(2100) ≤ 0), and X(t*) ≤ B2.

    out['cond_median'] = round(float(np.median(succ)), 2) if len(succ) else None
    return out

    return [round(float(np.percentile(v, q)), 2) for q in qs] if len(v) else None
