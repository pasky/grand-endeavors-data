### 3. Model
Not an exponential quantity (a first-of-a-kind event), so: slip-discounted proponent dates
with structural floors, first success across funded programmes, weighted with a reference class.
- year_i = stated_i + (target_i − stated_i) × F_i, F_i = 1.8 × exp(N(0,0.25) shared + N(0,0.30) own)
- floors (construction cannot be compressed): Helion 2029.0 (Orion construction from 2025.6 +
  ~3.5 yr build/commissioning), CFS 2031 (SPARC Q>1 ~2027 + ARC build), TAE 2031,
  Tokamak Energy 2032, Biblis 2033
- D0 = first of any (no per-programme failure odds: no ledger record measures them; Helion's
  miss is already inside F) → p10 2029.0, p50 2031.6, p90 2036.2
  (F 1.5: p50 2030.3; F 2.0: 2032.5; F 3.0: 2036.9)
- D1 (range only) = per-programme success odds Helion 0.5, CFS 0.6, TAE 0.3, TE 0.4, Biblis 0.3,
  plus a fallback wave (STEP/DEMO/next private generation, 2026 + lognormal median 24 yr)
  → p10 2029.4, p50 2034.7, p90 2044.2
- Reference class R (bg): CP-1 Dec 1942 → Obninsk 1954 / Calder Hall 1956 / Shippingport 1957
  = 11.5–15 yr; from NIF gain > 1 (Dec 2022): uniform 2034.5–2038 (p50 2036.2)
- Mixture M0 = 2/3 D0 + 1/3 R (same weights as prev; the evidence-based median case);
  M1 = 2/3 D1 + 1/3 R (range).

## Milestone: grid-parity — "Fusion LCOE falls below $100/MWh, competitive with gas"

### 1. Gap
Quantity: fusion LCOE (taken as real 2025 $). No plant runs, so it is unmeasured. Only
independent estimate: FOAK > $150/MWh (2023-01-01-lindley-fusion-foak-lcoe-rv). Neighbours:
new fission $142–222, gas CC $41–108 (avg $78) (2025-01-01-lazard-lcoe-2025-rv). Proponent:
CFS NOAK $50–100 (2025-01-01-cfs-fusion-noak-lcoe, legacy projection; cannot lift a status).
Gap at FOAK median $170 (inside Lindley's bound, below fission midpoint): 1.7× (≥ 1.5×).

### 2. Data / proxy
No fusion cost series exists. Proxy chain: (a) First Watt timing (above); (b) Wright's law from
FOAK, learning calibrated on the closest capital-intensive, site-built generator in the ledger:
offshore wind (lcoe-offshore-wind-irena 208/155/127/89/81/79 $/MWh 2010–2024; log slope
−7.3 %/yr; ~18 % per doubling with ~3 → ~83 GW cumulative, bg); onshore −8.7 %/yr, solar
−15.0 %/yr (lcoe-onshore-wind-irena, lcoe-solar-pv-irena) as upper bounds. LCOE of a new
generator tracks $/kW and capacity factor, which fall with cumulative build-out. Counter-class:
fission (Lazard new fission $142–222 today; fast breeders never competitive, bg).

### 3. Model
Learning curve: LCOE_n = FOAK × (1 − LR)^n, n = ln(FOAK/100) / −ln(1 − LR) doublings of
cumulative capacity. year = FW + 2 (follow-on orders) + n × Td.
Deterministic (FW 2034, Td 3 yr): gap 1.5 → n 3.85/2.91/2.04 at LR 10/13/18 % → 2047.5/2044.7/2042.1;
gap 1.7 → n 5.04/3.81/2.67 → 2051.1/2047.4/2044.0; gap 1.9 → 6.09/4.61/3.23 → 2054.3/2049.8/2045.7.
Offshore-wind rate check: ln(1.7)/0.076 = 7.0 yr after FW + 2 → ~2043.
**v3 arithmetic error**: it computed n = ln(gap)/−log2(1 − LR) (mixed bases), e.g. 2.67 instead
of 3.85 doublings for gap 1.5 at LR 10 %: n understated by a factor ln 2 = 0.69; on the same MC draws the wrong formula gives a conditional median of 2042.8 vs 2045.9 (unconditional 2045.4 vs 2049.3).
MC: FW from M0 (First Watt) with 7 % never; FOAK lognormal median $170, sd 0.28 (80 % $119–243;
P(FOAK < 100) 2.9 %); LR U(8–20 %); Td U(2–4 yr); fission-like no-learning branch 20 %
(never < $100 unless FOAK already is); truncate at 2100.
