## Triage method

Effective events = published <= 2026-10-28, minus ids listed in any record's `supersedes`
(365 -> 272). In-window = date overlaps 2025-10-28..2026-10-28 (a partial date ending no later
than its publication), as ledger.py's in_momentum_window. 225 events are in the window; all of
them (not only challenge-tagged) were scanned for advances and setbacks on each challenge's
wording. Script:

```python
import json
ev=[json.loads(l) for l in open('ledger/events/robots-hardware.jsonl')]
ev=[e for e in ev if e['published']<='2026-10-28']
sup=set()
for e in ev:
    s=e.get('supersedes')
    if s: sup.update(s if isinstance(s,list) else [s])
eff=[e for e in ev if e['id'] not in sup]
def inwin(d):
    if len(d)==4: end=d+'-12-31'; start=d+'-01-01'
    elif len(d)==7: start=d+'-01'; end=d+'-31'
    else: start=end=d
    return end>='2025-10-28' and start<='2026-10-28'
print(len(ev),len(eff))   # -> 365 272
for e in sorted(eff,key=lambda e:e['date']):
    if inwin(e['date']): print(e['id'], e['date'], e['published'], e['kind'],
                               e['verification']['status'], e['topics'], e['claim'][:400])
```

Substantive = step change, verified/corrected event, resting on more than the proponent's word
(peer review, independent measurement, replication or third-party reporting). Announcements,
specs, projections, funding and orders are context.
