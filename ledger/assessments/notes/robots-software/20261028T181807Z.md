## Method (RUBRIC.md §7)

Window (2025-10-28, 2026-10-28]. Events: effective robots-software events tagged with the challenge,
published <= 2026-10-28; records named in another record's `supersedes` and withdrawal tombstones
dropped; an event is in the window when its date span (ending no later than its publication)
overlaps it (same rule as core/ledger.py `in_momentum_window`). Legacy records in the window
(2025-dated SWE-bench, PersonQA, sub-1% hallucination, McKinsey, Lyapunov, AI drugs) were read as
context only and are not listed. Substantive = step change + verified/corrected event + more than
the proponent's word. Event counts were not used.

Triage script (run per challenge from data/ledger):

```python
import json,sys,calendar
AS='2026-10-28'; FROM='2025-10-28'
recs=[json.loads(l) for l in open('events/robots-software.jsonl')]
recs=[r for r in recs if r['published']<=AS]
sup=set()
for r in recs:
    s=r.get('supersedes')
    if s: sup.update(s if isinstance(s,list) else [s])
def span(d,pub):
    p=d.split('-')
    if len(p)==3: a=b=d
    elif len(p)==2:
        y,m=map(int,p); a=f'{d}-01'; b=f'{d}-{calendar.monthrange(y,m)[1]:02d}'
    else: a=f'{d}-01-01'; b=f'{d}-12-31'
    return a,min(b,pub)
ch=sys.argv[1]
for r in sorted(recs,key=lambda r:r['date']):
    if r['id'] in sup or r.get('withdrawn'): continue
    if ch not in r['topics']: continue
    a,b=span(r['date'],r['published'])
    inw = b>=FROM and a<=AS
    if len(sys.argv)>2 or inw:
        print(('IN ' if inw else 'OUT'),r['id'],'|',r['date'],'pub',r['published'],'|',r['kind'],r['verification']['status'])
        print('   ',r['claim'])
```
