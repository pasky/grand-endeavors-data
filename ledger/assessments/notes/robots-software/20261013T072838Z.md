**Range model (eta_mc.py).** Split-lognormal effort (10/50/90 as stated per milestone) and doubling

made_at (no achievement event). p50 is taken from the deterministic central case (the MC median sits a
few months later only because the doubling-time distribution is right-skewed; same calendar year).

## Milestone: The Linux Kernel Patch (assumes gate away)

1. **Gap.** Quantity: an openly AI-submitted 10k+ line patch accepted into Linux (or equivalent critical
   infra). Precursor: one fully LLM-written patch merged for Linux 6.15, human-submitted, undisclosed,
   size not stated (2025-06-01-lwn-llm-patch-merged-615-rv). Capability needed: the human effort of a
   substantive, reviewable 10k-line series ≈ 1,500 h (≈ 9 person-months at ~30–50 polished lines/day;
   range 500–4,000 h). Driver: METR 50% horizon (one accepted patch suffices; submitter can iterate and
   select) = 1,044.78 min (17.41 h). Gap 90,000/1,044.78 = 86.1× = 6.43 doublings.
2. **Trend.** metr-50-horizon-by-release window OLS 3.45 mo (table above). Context: SWE-bench
   Verified 1.1% (Mar 2024) → 80.9% (Nov 2025) (legacy) shows real-repo issue resolution rising as fast.
3. **Model.** Exponential (capability metric), from the last measured point 2026-04-07.
   6.43 × 3.45 = 22.2 mo → 2028.11. + 0.5 yr review/merge (a 10k-line series needs several revision
   rounds across ~2 kernel cycles of 9–10 weeks) → **2028.61**. No policy lag (assumed gate).
   Range-only: the real-codebase gap (the corrected SWE-bench weak-test study, 2024-10-01-…-wd: 12.47%
   → 3.97% resolution once suspicious passes are removed, ≈1.65 doublings, on 2024 agents and a
   different benchmark — it does not measure METR-to-kernel, so it only widens the range).
   MC (effort 500/1,500/4,000 h; D 2.97/3.45/5.97; gap sd 1 doubling; lag 0.25/0.5/1.5 yr;
   p_achieved 0.95): unconditional p10 2028.04, p50 2028.98, p90 2031.39; conditional p10/50/90
   2028.03/2028.92/2030.68. Deterministic fast case: 500 h at 2.97 mo → 2027.71.
4. **Cross-checks.** Fitted-trend start (872 min instead of 1,045) → 2028.69. Long-run 5.97 mo →
   2029.96. AISI 8 mo → 2031.05 (≈ p90). Prev ETA (v3) p50 2029 — it counted the six unmeasured months
   twice (endpoint rate including them, and extrapolating from made_at instead of 2026-04-07).
   Reference class: Rust-for-Linux, ~12k lines, about 20 months RFC → merge (background, not a ledger
   event; upper-end review floor, human-written, contentious). No proponent date in the ledger.
5. **Chance and quantiles.** p_achieved 0.95 (as if the gate held; residual risk: horizons plateau far
   below a person-year of work at 50%, or AI development is halted). p10 2028, p50 2028, p90 2031.

6. **Cruxes.** Earlier: METR point ≥ ~3,600 min (50%) for a post-April-2026 model; any multi-thousand-

   (e.g. < 1,800 min by 2027); measured horizons on messy real-codebase tasks far below METR's suite;
   review of large AI series taking > 1.5 yr.
