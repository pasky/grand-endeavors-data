## Common conventions and fixes (all three milestones)

- **Calendar-year encoding (fix of an error in prev's working, rule 7 b).** An outcome at continuous
  date t counts in calendar year floor(t); quantile q is the first calendar year by whose end
  P(achieved) >= q. Prev's Export and Homestead scripts reported P(t <= 2033.0) as "by end-2033",
  i.e. they rounded every quantile up a year (reproduced: Export raw quantiles 2028.84/2032.97/2072.49
  were reported 2029/2033/2073; Homestead 2036.51/2040.84 reported 2037/2041). The Deluge already used
  "calendar year whose total reaches 100 kt", so the encodings now agree. This moves Export and
  Homestead quantiles by up to -1 year with no change in the forecast itself (robots-software audit #5:
  document the calendar-year encoding; export all quantiles from one distribution, done here).
- **One distribution, common random numbers** (climate-ceiling audit #4, robots-hardware #6): every
  p_achieved and quantile comes from the same Monte Carlo (N = 400,000); sensitivities change one input
  on the same draws. The final scripts and their full output are inlined at the end (executable artifact).
- **Named failure scenarios with event definitions** (cross-section RUBRIC-WIDE MAJOR "incomparable
  priors"; RUBRIC v5 §4.1 step 5): each p_achieved shortfall is split into named scenarios, each with a
  reference-class denominator where one exists, labelled assumed, with low/high sensitivities.
  Shared risks are flagged: a century-long collapse of space access (debris, catastrophe, war) is
  common to all three; demand stagnation links the Deluge and the Homestead.
- **Floors vs lags vs priors** (cross-section RUBRIC-WIDE MAJOR "inconsistent evidence bar"): literal
  floors are only the 1-year operation of the Homestead; every duration is labelled sourced or assumed,
  and each assumed duration has a near-zero alternative as a sensitivity.
- **Discount clock** (cross-section RUBRIC-WIDE minor "discounts"; RUBRIC §4.1 step 4): proponent dates
  are discounted on the time remaining from the assessment date (2026.79), with programme-specific
  discount factors backed by dated comparisons.
- **Missing reports** (robots-hardware RUBRIC-WIDE minor #7): no rockets event dated 2026 has been
  gathered, so 2026 is unmeasured, not "nothing happened". The Export materials hazard runs from 2026.0
  (the last gathered evidence is Nov 2025), so a sale that happened but is unrecorded keeps its mass.
- Findings that do not apply: METR fit drift (cross-section minor), and the DEFINITION findings for

One Monte Carlo per milestone; every quantile and p_achieved comes from the same
distribution. Sensitivities reuse the same random draws (common random numbers),
changing one input at a time. Memory: N=400k float64 vectors, a few dozen at once (<100 MB).

Year encoding: an outcome at continuous date t counts in calendar year floor(t)
(Deluge: the calendar year whose total first reaches 100 kt). Quantile q = the first
calendar year Y with P(achieved by end of Y) >= q; null if that is past 2100.
Usage: uv run --with numpy python eta.py [prev]   ("prev" reproduces the 20261013T133118Z models)
"""
import sys
import numpy as np

N = 400_000
MADE = 2026.79  # 2026-10-14
PREV = len(sys.argv) > 1 and sys.argv[1] == "prev"


def split_ln(rng, med, lo10, hi90, n):
    """log-split-normal with median med and 10/90% points lo10/hi90."""
    z = rng.standard_normal(n)
    sl = np.log(med / lo10) / 1.2816
    sh = np.log(hi90 / med) / 1.2816
    return med * np.exp(np.where(z < 0, z * sl, z * sh))


def quantiles(t):
    t = np.where(np.isfinite(t), t, np.inf)
    yr = np.floor(t)
    ok = yr <= 2100
    p_ach = ok.mean()
    out = {"p_achieved": round(float(p_ach), 3)}
    srt = np.sort(yr[ok])
    for q in (0.1, 0.5, 0.9):
        k = int(np.ceil(q * len(t))) - 1  # unconditional rank
        out[f"p{int(q*100)}"] = int(srt[k]) if k < len(srt) else None
    if ok.any():
        c = np.percentile(srt, [10, 50, 90])
        out["cond"] = [int(np.floor(x)) for x in c]
    return out


def cdf(t, years):
    yr = np.floor(np.where(np.isfinite(t), t, np.inf))
    return {y: round(float((yr <= y).mean()), 3) for y in years}


# ---------------------------------------------------------------- Deluge
def deluge(p_fail=0.12, slope_med=0.3695, sd_lo=0.133, sd_hi=0.078, stall=None, ton=1.0, seed=20261014):
    rng = np.random.default_rng(seed)
    z = rng.standard_normal(N)
    g = slope_med + np.where(z < 0, z * sd_lo, z * sd_hi)  # log-slope per yr
    e = rng.normal(0, 0.07, N)  # level noise (ln) on the crossing
    u = rng.random(N)
    u2 = rng.random(N)
    stall_len = rng.uniform(5, 15, N)
    gap = np.log(100000 / (3194.0 * ton))
    with np.errstate(divide="ignore", invalid="ignore"):
        t = np.where(g > 0, (gap + e) / g, np.inf)
    t = np.maximum(t, 0.0)
    if stall is not None:  # sensitivity: P(stall) of a 5-15 yr flat spell before the hand-off
        t = t + np.where(u2 < stall, stall_len, 0.0)
    yr = 2025 + np.ceil(t)  # first calendar year with total >= 100 kt
    yr = np.where(u < p_fail, np.inf, yr)
    return yr


# ---------------------------------------------------------------- Export
def export(pA=0.5, start_med=1.7, start_lo=0.8, start_hi=3.6, prog_med=4.0, prog_lo=2.5, prog_hi=7.0,

    tA = np.minimum(tA, np.where(rng.random(N) < broad, start, np.inf))

    t = np.where(rng.random(N) < common, np.inf, t)
    return t


# ---------------------------------------------------------------- Homestead
def homestead(gap_med=7.5, gap_lo=4.5, gap_hi=13.5, common=0.08, ab_us=0.30, ab_cn=0.25,
              d_us=(1.8, 1.3, 2.8), d_cn=(1.15, 1.0, 1.5), clock="rubric", floor=1.0, seed=11):
